# Stockva — game interface

A city-building sandbox, starting on an empty island. Gameplay is the interface.

- Full-screen terrain; no dashboard, decorative charts, prebuilt city, or marketing cards.
- Continuous compact game chrome: slate-blue top resource bar, bottom construction bar, minimap and camera controls.
- Navy and steel panels (#192a34, #283f4c), construction yellow (#f4cd60), near-white text (#e7eef2).
- Square, lightly beveled tools; actual game sprites in the construction catalogue.
- Buildings, roads and services must all be placed by the player. Contextual inspectors only appear on selection.
- System sans typography for controls, monospace for resources. Concise game instructions.
